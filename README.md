# CASER

CASER is Case Automated Search of Electronic Records. It searches public U.S. federal court filings. A party name, a keyword, or a case title starts the search. CASER reads district, bankruptcy, and appellate courts and returns the court, the date, a short description, and a link to the filing.

CASER does not give legal advice.

- iOS app for federal case search and alerts
- [caserlegal.com](https://www.caserlegal.com)
- [Docket search](https://www.caserlegal.com/v1/docket-search)
- 8ti, a self-hosted legal document search engine
