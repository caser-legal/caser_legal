# caser_legal / README.md

⚖️ CASER searches U.S. federal court filings. A party name, a keyword, or a case title starts the search. CASER scans 300+ federal courts and returns the court, the date, a short description, and a link to the filing.

🧠 About 🧠 

CASER is Case Automated Search of Electronic Records. The iOS app and caserlegal.com (https://www.caserlegal.com) search recent public federal filings. The same search is on Muse at caserlegal.com/v1/docket-search (https://www.caserlegal.com/v1/docket-search).

A search covers district, bankruptcy, and appellate courts, with an optional state and date window. Each search reads public court records. CASER does not give legal advice.
